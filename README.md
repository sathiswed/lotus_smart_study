# Lotus Smart Study

Textbook-grounded Classes 8-12 assessment platform with a Next.js frontend,
FastAPI backend, PostgreSQL database, OpenAI-compatible question generation,
and private S3-compatible textbook and handwritten-answer storage. Existing
CBSE Class 8 Mathematics content remains the currently preloaded curriculum.

- Product requirements: `docs/PRD.md`
- Approved scope and decisions: `docs/DECISIONS.md`
- API and database contracts: `docs/API_CONTRACT.md` and `docs/DATABASE_SCHEMA.md`
- Implementation status: `docs/IMPLEMENTATION_PLAN.md`
- Owner-run installation and validation: `docs/MANUAL_SETUP.md`

Codex did not run builds, tests, migrations, application servers, or deployment.
